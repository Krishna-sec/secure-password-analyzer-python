# secure-password-analyzer-python# 🔐 Python Password Strength Checker

A Python-based Password Strength Checker that analyzes password security using regex and multiple validation techniques.

The program evaluates password strength based on:

* Password length
* Uppercase letters
* Lowercase letters
* Numbers
* Special characters
* Repeated characters
* Common weak passwords
* Simple sequences

---

## 🚀 Features

* Password strength scoring system
* Weak / Medium / Strong classification
* Regex-based validation
* Suggestions for stronger passwords
* Detection of common weak passwords
* Sequence and repetition detection

---

## 🛠️ Technologies Used

* Python
* Regex (`re` module)
